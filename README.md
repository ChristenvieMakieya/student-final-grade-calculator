# Student Final Grade Calculator

## 📌 Description
Built a grade calculation application to help students accurately compute final results, using C# to combine multiple assessment scores into final grades.

## 🛠️ Technologies Used
- C# methods and conditional statements.
- Mathematical Logic
- Input Validation

## ⚙️ Features
- Accepts multiple marks
- Calculates final grade
- Determines academic outcome

## 📚 What I Learned
- Clean logical design
- Edge case handling
- Code readability
